# 验收失败记录：SAM3D Body 姿势参数优化（E 段）

- 日期：2026-10-21
- 验收对象：`ground_pipeline` 配准链 E 段「MHR 姿势参数小步优化」
- 测试输入：`images/5306c1d3gy1hsktgsqco6j20sg11wq4s.jpg`（人物仰卧抬腿）
- 相关代码：`ground_pipeline/ground_pose.py` 的 `refine_rigid_to_scene`（原 `refine_to_scene` / `_refine_loop` 已删除）
- 结论：**不通过**

## 1. 现象

- 网格与地面接触已经正确：接触区平均高度 `0.98 cm → -0.07 cm`，穿透顶点占比 `0.16%`。
- 但角色姿势与图像不符：躯干/四肢被优化项拉偏，网格不再是 SAM3D 预测的姿势。
- 该问题不是个别张图的偶然现象，而是「在关节参数空间求解场景损失」这一做法本身决定的。

## 2. 量化证据（末次实机运行）

| 指标 | 数值 | 说明 |
| --- | --- | --- |
| `refine.status` | `applied`，80 it | 优化确实生效，非降级 |
| `delta_pose_rms` | 0.0508 rad（≈2.9°） | 130 维关节增量的 RMS |
| `scale_factor` | **1.0171** | 人体整体尺度被放大 1.7%，体型被改写 |
| `delta_rot_deg` | 0.13° | 全局朝向几乎没动 |
| `delta_trans_m` | `[-0.004, 0.014, -0.003]` | 平移幅度仅 1.4 cm |
| `max_vertex_shift_m` | 0.133 m | 单个顶点最大位移 13.3 cm |
| `vertex_reg_m2` | 0.00236 | 采样点平均位移 ≈4.9 cm |
| `contact_height_*` | 0.0098 → -0.0007 m | 接触已达标 |
| `penetration_ratio_*` | 0.0 → 0.0016 | 可忽略 |
| `rmse_m → rmse_final_m` | 0.2642 → 0.2845 m | 关键点残差反而恶化 2 cm |

关键点：`delta_rot_deg` 只有 0.13°、`delta_trans_m` 只有 1.4 cm，但 `max_vertex_shift_m` 达 13.3 cm、尺度变化 1.7%。说明位移**不是来自刚体搬动，而是来自关节与尺度本身被改写**，这正是姿势走形的来源。

## 3. 根因分析

1. **自由度与监督不匹配**：E 段放开 130 维关节 + 3 维全局旋转 + 3 维平移 + 1 维对数尺度，共 137 维；而可用约束只有稀疏的 DepthPro 点云（含噪声）、70 个 2D 关键点和一条弱正则。欠定问题，优化器会用「改姿势」去凑接触/穿透/Chamfer。
2. **尺度被当作自由度**：`dlog` 直接改变人体比例，1.7% 缩放已足以让四肢位置偏出数厘米，且无法用「姿势」解释。
3. **接触项可被整体平移"作弊"**：接触损失只约束最低 600 个顶点，与其改姿势不如整体下沉；一旦再叠加 Chamfer，局部肢体就被单独拖走。
4. **2D 关键点权重不足以钉住上身**：投影项按米计量级远小于接触/穿透项，且只在 `z>0` 的 63 个点上生效。
5. **本质上姿势应由 SAM3D 决定**：任何对 MHR 参数的修改都等价于重新预测姿势，而缺少图像先验的参数微调只会破坏它。

本轮同时确认了一个与失败无关、但影响判断的事实：该图人物是**仰卧抬腿**，双脚本来就在空中。此前「脚底离地 0.19 m」不是误差，基于脚部贴地的下肢吸附方案从一开始就建立在错误前提上。

## 4. 验收失败判定

- 接触指标：通过。
- 姿势保真：不通过（顶点最大位移 13.3 cm、尺度漂移 1.7%、关键点残差恶化）。
- 按「姿势不得被改写」的硬要求，**E 段参数优化方案整体废弃**。

## 5. 新方案：刚体收缩（只改整体平移/旋转）

### 5.1 原则

把「场景贴合」从**非刚体参数空间**收缩到**刚体自由度**：网格内部几何完全冻结，只做整体平移（必要时才整体旋转）。姿势 100% 沿用 SAM3D 输出，不再可能被场景损失改写。

实测收敛后的最终形态是**只保留 1-DOF 平移**：

| 尝试 | 结果 | 结论 |
| --- | --- | --- |
| 6-DOF（旋转 8° 上限） | 转角打满 8°，`max_vertex_shift 8.9 cm`，`rmse 0.2642 → 0.2997` | 转角改变角色朝向，画面一致性变差 |
| 6-DOF（旋转 5° 上限） | 转角仍打满 5°，接触 `0.24 → 1.04 cm`（变差） | 旋转不能改善接触，只是换个姿势歪 |
| 3-DOF 平移 | `max_vertex_shift 13.8 cm`，接触 `0.24 → 1.26 cm` | 横向被 Chamfer/投影拉走，整体漂移 |
| **1-DOF 法向平移** | `max_vertex_shift 0.63 cm`，接触 `0.24 → -0.39 cm`，穿透 0 | 通过 |

### 5.2 变量与冻结项

- 优化变量：`dtrans(3)`，但**只有沿地面法向（世界 z）的分量生效**：`shift = (dtrans · z_world) · z_world`，横向与纵深沿用 A→D 的结果。
- 旋转：`drot(3)` 仅在显式传入 `max_rotation_deg > 0` 时参与优化，**默认 0 即关闭**（关闭时不把 `drot` 放进优化器，避免 0 除法产生 NaN 梯度）。
- 冻结：130 维关节、全局朝向、手部、尺度/形状/表情参数、外层相似变换（`s, R, t`）、逐顶点位移。
- 硬上限：转角 ≤ `max_rotation_deg`（默认 0°），顶点总位移 ≤ 0.15 m（`max_vertex_shift_m`），超限即 `rejected` 并保留原网格。

### 5.3 目标函数

`L = w_c·接触 + w_p·穿透 + w_ch·Chamfer + w_kp·2D 投影 + w_r·旋转正则 + w_t·平移正则`

- 接触：**最低 60 个顶点**（≈0.3%，避免为压平整个贴地曲面而强行旋转）到 `contact_target`（接触点中位数，且 clamp ≤ 0）的均方高度。
- 穿透：采样顶点 `relu(-z-1cm)²`。
- Chamfer：采样顶点到人物点云最近点的均方距离。
- 2D 投影：把**同一刚体变换**作用到 `keypoint_cam`，比较重投影像素误差（换算成米）。
- 正则：`|drot|²`、`|dtrans|²`，避免无谓的大幅旋转/漂移。

### 5.4 实现要点

- 不再调用 MHR 前向、不加载/搬运 `head_pose`、不占用 GPU；纯 CPU + torch 自动微分，120 步内完成。
- 输出与现有 E 段字段兼容：`status`、`iterations`、`delta_rot_deg`、`delta_trans_m`、`contact_target_m`、`contact_height_before_m/after_m`、`penetration_ratio_before/after`、`max_vertex_shift_m`、`losses`。
- 原有 B（trimmed ICP，仅平移）、C2（接触面 ≤5° 转平）、D（1-DOF 垂直吸附）保留，作为初值。

### 5.5 新方案验收标准

1. 网格内部相邻顶点距离分布与优化前**完全一致**（刚体不变性，可用边长直方图校验）。
2. `delta_rot_deg = 0`（默认关闭旋转），`max_vertex_shift_m ≤ 0.15 m`（期望量级为毫米）。
3. 接触高度 `|after| ≤ 1 cm`，穿透顶点占比 `≤ 0.5%`。
4. 关键点残差 `rmse_final_m` 相对**刚体精修前**的 `rmse_before_refine_m` 变化不超过 1 cm（注意：`rmse_m` 是 Umeyama 阶段的值，C2 接触面转平与 D 吸附本身就会改变它，不能直接作为 E 段的基线）。
5. 3 视图目视：肢体相对关系与 SAM3D 原网格一致，仅整体位置/朝向变化。

### 5.6 风险与回退

- 若真实偏差主要来自姿势错误（而非摆放），刚体方案无法修正；此时应回到「换更好的姿势模型/多视图」而不是继续加自由度。
- 若刚体精修导致网格滑离人物点云（Chamfer 变差），直接跳到 `rejected`，保留 C2/D 的结果。
- 回退点：删除 E 段即可回到 A→D 的纯几何配准链。

结论：E 段只做了 6.3 mm 的垂直下落，接触从 +2.4 mm 变为 -3.9 mm（轻微压入、无浮空），穿透为 0，关键点残差仅变化 +0.9 mm，**姿势与尺度完全未被触碰**。

补充说明：`rmse_m = 0.2642` 与 `rmse_before_refine_m = 0.3055` 之间的 4.1 cm 差异来自 **C2 接触面 5° 转平 + D 吸附**（`contact_plane.applied_deg = 5.0`、`ground_snap.offset_m = -0.0511`），与 E 段无关；若后续要继续压低该项，应排查 C2 的 5° 上限与枢轴选择，而不是在 E 段放开自由度。

**该版仍判定为效果不足**：E 段本身已是纯 1-DOF 刚体，但 A 段的相似变换把网格整体缩到了 0.79 倍、并平移了近 1 m，角色在画面里变成「小一截且错位」的模型。E 段无法修正上游引入的尺度与位置偏差。

## 7. 根因：A 段关键点 Umeyama 的相似变换

A 段用「SAM3D 相机系 3D 关键点 ↔ DepthPro 在关键点像素处的深度反投影点」做加权 Umeyama，解得 **`scale = 0.7878`**、`translation ≈ [-0.82, -0.33, 0.42] m`。

问题在于两侧数据的误差结构完全不同：

- SAM3D 的关键点是**模型自己估的米制人物**，本身已满足它自己的隐式地面；
- DepthPro 的深度在人体边缘、毛发、衣物处系统性偏大/偏小，且存在整体深度尺度偏差；
- Umeyama 把这两者的差异全部吸收进 `s`，于是「深度尺度不准」被解释成「人变矮了」。

`scale 0.79` 等价于把身高砍掉 21%，叠加 C2 的 5° 转平与 D 的 −5.1 cm 吸附，最终 `rmse` 从 0.2642 恶化到 0.3055，目视即为「姿势走样 + 整体缩水」。

## 8. 新方案：相机系地面锚定（刚体、不缩放）

### 8.1 依据

`plane_normal` / `plane_d` 本身就是**相机坐标系**下的地平面（`n·p + d = 0`）。而 SAM3D 的网格 `pred_vertices + pred_cam_t` 也在同一个相机系里，且原始输出就已经「站在」这张图上——实测原始网格相对检测地面的高度分布：

| 指标 | 5306 图 | 含义 |
| --- | --- | --- |
| `min` | −0.0953 m | 最低点已轻微入地 |
| `p1` | −0.0861 m | 1% 分位 |
| `p5` | −0.0624 m | 5% 分位 |
| `p50` | +0.1437 m | 中位数 |
| `max` | +0.8411 m | 最高点 |
| `mesh_low_plane_tilt_deg` | **3.47°** | 最低 1% 顶点拟合面相对地面的倾角 |

也就是说：**SAM3D 在相机系里本来就贴地**，唯一需要修正的只是「自带接触面与检测地面之间 3.5° 的倾角 + 几厘米的高差」。用 0.79 缩放和米级平移去「配准」是过度修正。

### 8.2 算法

`_align_pose_mesh_by_ground(vertices, plane_normal, plane_d)`，输出 `(R, t)`，**尺度恒为 1.0**：

1. **接触面拟合**：取沿地面法向 `up = -plane_normal` 高度最低的 `max(40, 1% × N)` 个顶点，SVD 拟合平面法向，3 轮截断（丢弃残差 > median + 3·MAD）后得 `contact_normal`（相机系）。
2. **转平**：Rodrigues 把 `contact_normal` 旋到 `up`，枢轴为接触点质心。倾角 `> 10°` 视为接触面假设不成立，直接 `skipped` 回退 Umeyama；倾角 `< 0.3°` 视为无需旋转。
3. **落位**：旋转后取 0.5% 分位高度，沿 `up` 平移使其归零，平移量 clamp 到 ±0.30 m。
4. 之后仍走原有的 **D 垂直吸附 + E 1-DOF 刚体精修**；锚定成功时跳过 B（ICP）与 C2（接触面转平），避免二次扰动。

### 8.5 修复：竖直面剔除

`extract_ground` 新增 `min_vertical_component`（默认 0.5）：

- 相机系 y 轴向下，地面法向的 `|n_y|` 应接近 1，竖直面接近 0；
- RANSAC 候选法向 `|n_y| < 0.5` 直接跳过（允许约 60° 俯仰）；
- SVD 精化后的平面再校验一次，防止混合内点把法向拉回墙面；
- 掩码内没有水平面时返回 `422 无法拟合水平地面平面（N/iterations 个候选因接近竖直面被剔除）`。
