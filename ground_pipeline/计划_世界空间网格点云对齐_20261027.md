# 世界空间 SAM-3D 网格 × MoGe-2 点云 对齐可视化计划（2026-10-27）

## 1. 目标

在**世界坐标系**（`ground_world_v1`）下验证并展示 SAM-3D 网格与 MoGe-2 深度反投影点云是否重合，输出可目视 + 可量化的对齐面板；地面不可信（`ground=rejected`）时退回 `camera_v1`，不做任何地面变换。

验收标准（grounded 场景）：

| 指标 | 目标 |
|---|---|
| 网格最低点世界 z | ≈ 0（构造保证） |
| person 点云最低点世界 z | \|z\| < 0.02 m |
| person 点云→网格最近距离 中位数 / P90 | < 0.03 m / < 0.08 m |
| 三视图目视 | 点云轮廓贴合网格表面，无整体上下错位 |

## 2. 现状与问题诊断

### 2.1 已推翻的假设：点云**不需要**补落地平移（实测结论）

计划初稿假设“网格被 `landing_shift` 整体抬高 `dz`，点云没补，所以两者上下错位”。实测证伪：

- `GroundTransform` 的平移满足 `plane_d_camera = -translation[2]`（[ground_retarget.py](file:///g:/UGit/Phy-SIC/ground_pipeline/ground_retarget.py#L350-L393)），即**世界 z=0 就是 MoGe-2 深度拟合出的地面**，`pc @ rot.T + tvec` 之后点云已天然落地；
- `ground_snap.offset_m` 是把 SAM-3D 网格最低点吸附到 z=0 的修正，只属于网格；
- 若再给点云叠加 `dz`（0.078 / 0.076 m），点云最低点会从 0.004~0.010 m 抬到 0.086~0.088 m（明显浮空），与验收标准 |z|<0.02 冲突；
- 代码已回退：`_scene_points()` 与 `person_point_cloud()` 均不再叠加 `dz`。

### 2.2 其他待处理差异

| 差异 | 现状 | 影响 |
|---|---|---|
| 采样范围 | 场景面板点云取相机半径 4 m 内全部像素 | 含大量背景，淹没人体对齐判断 |
| 人物筛选 | 专用面板改为 person mask 约束 | 可单独评估人体区域对齐 |
| 尺度一致性 | MoGe-2 focal/depth vs SAM-3D 网格自估 focal/depth 不同 | 存在源级尺度差，是主要残差来源 |
| 展示方式 | 网格、点云分处两个 3D 面板，并列不叠加 | 无法直接目视对齐 |

## 3. 方案

### 3.1 统一世界变换（最终实现：点云不补平移）

点云与网格使用**同一组** `rotation / camera_position` 进入世界系，但**不**给点云叠加 `ground_snap.offset_m`：

```python
pw = pc @ rot.T + tvec          # 相机系 → 世界系，z=0 即深度拟合地面
# 不写 pw[:, 2] += dz：offset_m 只属于 SAM-3D 网格的落地修正
```

- 依据：`plane_d_camera = -translation[2]`，点云变换后已天然落地（实测最低点 0.004~0.010 m）；
- `landing_m` 仍从 `world["ground_snap"]["offset_m"]` 读出，但仅作为**信息**展示在面板与 summary（`mesh_landing_offset_m`），不参与几何变换；
- rejected 场景网格与点云都留在 `camera_v1`，不做任何地面变换。

实现：`_scene_points(depth, focal, rot, tvec, grounded, cam_world)`（无 `z_shift`）、`person_point_cloud(..., grounded, rot, tvec)`（无 `dz`）。

### 3.2 新增专用对齐面板 `render_world_align.py`

复用 `render_scene_panel` 的 `fetch_case / to_display / _ortho_windows / shade_faces / project_ground_grid / pointcloud3d_panel`（模块无副作用，可直接 import），输出 2×3 版面：

- **第一行（三视图，叠加）**：front(x–z) / side(y–z) / top(x–y)，同一窗口内同时画
  - 点云（person mask 内、按相机深度着色，小点，`s≈1`）
  - 网格（半透明实体面 `alpha≈0.35`，或线框）
  - 地面参考网格（`z=0`，红色）
- **第二行**：
  - 3D 透视叠加（`focal_length=0.5`，点云 + 网格 + 地面 + 相机视锥）
  - 点→网格最近距离直方图（`scipy.spatial.cKDTree` 对网格顶点）
  - 指标卡：bbox 尺寸、最低 z、最近距离中位数/P90、缩放比

### 3.3 量化指标

以 person mask 筛选点云（`g["masks"]["person"]` 上采样到深度分辨率）：

1. `pc_min_z`：person 点云世界 z 的 1% 分位；
2. `nn_median / nn_p90`：person 点云到网格顶点的最近距离；
3. `bbox_ratio`：person 点云 bbox 尺寸 / 网格 bbox 尺寸（x, y, z 三轴）；
4. `surface_ratio`：距离 < 0.03 m 的点占比。

写入 `world_align_summary.json`。

## 4. 实施步骤

1. `render_scene_panel.py`：确认 `_scene_points` 不做地面平移（`pw = pc @ rot.T + tvec` 后直接返回），点云与网格共用同一世界变换。
2. 新增 `ground_pipeline/render_world_align.py`：CLI（`images --base --outdir --no-cache --dpi`）、复用上述 helpers、输出面板 + summary。
3. WSL 离线模式服务（`HF_HUB_OFFLINE=1`）下 `--no-cache` 重跑 6 张：`images/test_image` 4 张、`images/test_image2` 2 张。
4. 输出目录：`images/{test_image,test_image2}/moge2_visualization/world_align/`。
5. 校验 3.3 指标 + 目视三视图。

## 5. 风险与实测结论

- **源级尺度差（已实测，主要残差来源）**：SAM-3D 自估 focal 与 MoGe-2 focal 不一致，导致网格深度整体偏大。
  - `006d`：`f_sam=1243.9` vs `f_moge=788.2`（1.58×），SAM-3D 网格相机系 z 中心约 2.52 m，MoGe 点云 1.77~2.13 m → 最近距离中位 22.96 cm；
  - `90dc`：`f_sam=902.1` vs `f_moge=789.9`（1.14×）→ 最近距离中位 53.14 cm；
  - 服务内置 `_align_pose_mesh_to_depth()`（加权 Umeyama → trimmed ICP → 地面吸附 → 6-DOF 精修）在 `90dc` 上 `scale=1.0, rmse=0.3184 m`，对齐后仍有 27 cm 残差 → 属源级尺度/姿态拟合问题，**不是坐标系 bug**；
  - 本次按要求只报数、不改尺度，修正留待 Phase 2（按人体高度比整体缩放 / 改用 SAM-3D 自带 focal 反投影 MoGe 深度）。
- **点云噪声/遮挡**：mask 边缘与深度飞点抬高 P90，故以中位数为主判据。
- **地面被拒（rejected）**：`strvxj`（夹角 59.8°）、`sw6d1j`（34.2°）退回 `camera_v1`，指标中的 `*_min_z` 为相机系数值，不能按“落地”解读。
- **旧缓存**：grounded 旧响应无 `camera_space`，须 `--no-cache`；缓存不落盘时以摘要 json 留档。
- **服务依赖**：HF 不可达时必须 `HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1` 启动，否则 GroundingDINO 下载失败导致启动退出。

## 6. 交付物与实测结果

- 代码：`ground_pipeline/render_world_align.py`（新增）、`render_scene_panel.py`（点云不做地面平移）。
- 结果：每个测试图一张 `*_world_align.png` + 汇总 `world_align_summary.json`。

### 6.2 修正前后对比（是否给点云补 `offset_m`）

| 图 | pc_min_z（不补 / 补 dz） | nn 中位（不补 / 补 dz） |
|---|---|---|
| sqco6j | 0.0099 / 0.0864 | 9.09 / 10.16 cm |

结论：补 `dz` 会让点云整体浮空 8.6~8.9 cm，违反 `|z| < 0.02 m`，故**不补**；`nn` 变化在噪声量级内，说明 `dz` 不是残差来源。

### 6.3 结论

- 世界系坐标变换正确：grounded 场景网格最低点 0.004~0.012 m、person 点云最低点 0.004~0.044 m，与 `z=0` 地面同步（`006d` 点云最低点 0.0443 m 略超 2 cm 阈值，与其 23 cm 的尺度残差同源）；
- `z459j` 达到验收标准（nn 中位 4.43 cm、P90 8.28 cm）；`sqco6j` 接近（9.09 / 16.57 cm），残差集中在手/裙摆等末端；
- `test_image2` 两张（`006d` 22.96 cm、`90dc` 53.14 cm）未达标，根因是 SAM-3D 与 MoGe-2 的 focal/深度尺度差，非坐标变换问题；
- `strvxj` / `sw6d1j` 地面被拒，退回 `camera_v1`，不参与落地验收。
